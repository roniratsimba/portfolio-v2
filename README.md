# R. Portfolio — V4

Version recentrée sur une présentation plus éditoriale et professionnelle.

## Changements

- Identité visuelle simplifiée : `R.` au lieu de `Roro` dans l'interface.
- Header réorganisé : navigation au centre, langue FR/EN à droite, statut retiré.
- Projets présentés en grandes compositions paysage, avec la première capture comme visuel principal.
- Galerie plein écran pour les projets qui possèdent plusieurs captures.
- Captures portrait recadrées dans une composition paysage sur les cartes projet ; la galerie conserve l'image source en grand.
- Apparition progressive des projets et sections au scroll avec IntersectionObserver.
- Transition de fond : noir pour l'introduction et les projets, clair pour ingénierie/expérience/about, puis retour au noir pour contact.
- Suppression du texte de footer « Built with HTML, CSS & JavaScript. ».
- Descriptions des six projets réécrites avec un positionnement plus professionnel, sans inventer de résultats.
- Contact présenté comme « Une opportunité ? Discutons-en. » sans numéro de téléphone.
- Support FR/EN conservé.
- Support `prefers-reduced-motion` conservé.
